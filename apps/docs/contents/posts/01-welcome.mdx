# Bienvenue sur Hydroid AI

**Hydroid AI** est une plateforme d'intelligence et d'analyse de sécurité web conçue pour l'OSINT (Open Source Intelligence), le scraping web, l'analyse de données et la génération de contenu par IA.

---

## Fonctionnalités principales

### Scanner de sécurité web

Un scanner complet qui analyse une URL cible via 6 modules exécutés en parallèle :

- **En-têtes de sécurité** — Vérifie HSTS, CSP, X-Frame-Options et autres headers critiques
- **Analyse des cookies** — Détecte les attributs de sécurité manquants (Secure, HttpOnly, SameSite)
- **Configuration CORS** — Analyse les règles Cross-Origin Resource Sharing
- **SSL/TLS** — Vérifie HTTPS et la présence du header HSTS
- **Injection SQL** — Détecte error-based, time-based, union-based et boolean-based avec comparaison baseline
- **XSS** — Détecte les vulnérabilités XSS réfléchies via analyse de reflection de payload

### Analyse IA des résultats

Quand LM Studio est configuré, les résultats du scan sont envoyés à un LLM local qui génère un résumé des risques, des recommandations de remédiation et des actions prioritaires.

### Agents IA & Fine-Tuning

Configuration et gestion d'agents IA avec support pour le fine-tuning via Ollama et LM Studio.

## Stack technique

| Couche     | Technologie                         |
| ---------- | ----------------------------------- |
| Runtime    | Bun                                 |
| Backend    | Ts.ED v8 + Prisma + SQLite          |
| Frontend   | Next.js 16 + React 19 + Tailwind v4 |
| UI         | shadcn/ui (Radix UI)                |
| State      | Zustand                             |
| Validation | Zod + react-hook-form               |
| Monorepo   | Turborepo                           |

## Démarrage rapide

```bash
# Installation
bun install

# Backend
cd apps/api && bun run dev

# Frontend
cd apps/web && bun run dev
```

---

## Structure du projet

```
apps/api/        Backend Ts.ED
apps/web/        Frontend Next.js
apps/docs/       Documentation MDX
packages/security-core/   Types et utilitaires security
packages/scanner-web/     Analyseurs headers/cookies/CORS/SSL
packages/scanner-sqli/    Scanner SQL injection
packages/scanner-xss/     Scanner XSS
packages/ui/              Composants UI shared
```
